# footer-shapes · 使用说明

页脚**五形态**:排印式、栅格式、大字式、动效式、小字式。同一份数据、同一个骨架,换一个形态类就换一种信息密度取向。

## 什么时候用

- 站点底部要一个**不只是版权行**的收口:要么品牌当唯一大件,要么链接成栅格,要么联系语最大化。
- 需要**可切换**地比较五种排法,再定一个落地(承接方案评审)。
- 需要「栅格式」带可用的订阅表单(空 / 非法 / 合法三态回执都做全了)。
- 需要「动效式」的跑马灯与折叠 FAQ,且要求减速模式下自动退化成静态折行。

## 什么时候不用

- 只需要一行版权:用「小字式」里的 `.fs-small-meta` 一段即可,不必整包。
- 页脚要承载**多级站点地图**(三层以上导航):栅格式最多四列平铺,深层结构该用真正的 sitemap 区。
- 要求跑马灯文字可被搜索引擎完整索引:跑马灯是装饰层,正文链接请另放在列表里(预览里 `.fs-bar` 承担了这点)。
- 需要 cookie 同意横幅、语言切换等合规件:本包不管合规逻辑。

## 接入步骤

1. 拷两个文件(脚本只服务栅格式的表单,其余形态纯 CSS):

   ```text
   src/footer-shapes.css  →  assets/footer-shapes.css
   src/footer-shapes.js   →  assets/footer-shapes.js
   ```

2. 写一份骨架,选一个形态类:

   ```html
   <footer class="fs ft--typo" data-mode="light">
     <div class="fs-in">…</div>
   </footer>
   ```

3. 形态类五选一:`ft--typo` / `ft--grid` / `ft--large` / `ft--anim` / `ft--small`。**HTML 骨架不用改**。

## 标记对照与五形态

| 形态 | 类名 | 信息密度 | 适合 | 主件 |
|---|---|---|---|---|
| 排印式 | `ft--typo` | 低(2 行) | 工作室 / 品牌站:字标当唯一大件 | `.fs-wordmark` + `.fs-typo-meta` |
| 栅格式 | `ft--grid` | 高(四列) | 内容站 / SaaS:要给全量入口与订阅 | `.fs-cols` + `.fs-form` + `.fs-bar` |
| 大字式 | `ft--large` | 低(1 句) | 接单型个人 / 小团队:把联系语放到最大 | `.fs-huge` + `.fs-large-row` |
| 动效式 | `ft--anim` | 中 | 作品集:跑马灯给节奏,FAQ 兜常见问题 | `.fs-marquee` + `.fs-acc` |
| 小字式 | `ft--small` | 最低(1 行) | 工具 / 文档站:底部署名与合规链接 | `.fs-small-line` + `.fs-small-meta` |

实测高度(978px 宽、默认字号):414 / 295 / 379 / 418 / 128 px。

## 参数

| 变量 | 默认 | 说明 |
|---|---|---|
| `--fs-pad` | `clamp(24px,4vw,56px)` | 内边距;小字式自己覆写成上下更薄 |
| `--fs-ink` / `--fs-muted` | `--ink` / `--muted` | 正文与次要字 |
| `--fs-rule` / `--fs-rule-soft` | `--rule` / `--rule-soft` | 描边两档 |
| `--fs-accent` / `--fs-accent-ink` | `--accent` / `--accent-ink` | 焦点环与链接下划线;**小字回执用 `--accent-ink`** |
| `--fs-serif` / `--fs-mono` | `--serif` / `--mono` | 字标与小型大写用哪套字族 |

## 无障碍硬项

- 形态切换用 `role="tablist"` + `aria-selected`(预览里演示);真实站点若只落一个形态,不需要这套 tab。
- 跑马灯是**装饰**:第二份重复内容挂 `aria-hidden="true"`,读屏只读一遍;正文入口放在 `.fs-bar` 的真链接里。
- 折叠 FAQ 用原生 `<details>/<summary>`,键盘与读屏免费;`summary` 去掉了默认三角,用 `::after` 的 +/− 替代。
- 表单三态回执走 `aria-live="polite"`,且不替换用户已填内容(只有成功才清空)。
- `prefers-reduced-motion: reduce`:跑马灯停,并从「裁切长条」退化成**可折行的静态列表**(直接关掉动画会留下一条被切掉的静止文字)。

## 反模式

- **不要**给 `.fs-cols` 的列留 `min-width: auto`:长邮箱会把整列撑开造成横向溢出;必须 `minmax(min(150px,100%), 1fr)`。
- **不要**在跑马灯里放真实导航:它不可聚焦、不响应点击,是纯装饰。链接必须在外面另给一份。
- **不要**把 `ft--large` 的大字用在正文页中段:那一档是给「一句话收口」的,字号 `clamp(40px,9vw,108px)` 在列表里会撞行。
- **不要**在 `ft--small` 里堆四列链接:小字式的价值是「只用一行」,堆成栅格就变成劣化的栅格式。
- **不要**在动态字标上写 `font-weight: 200`(必要标记,但仅对支持可变轴的字族生效):不支持 `opsz` 的字族会落到系统衬线,字重仍取 200;若目标字族没有 200 字重,浏览器会合成假细体——所以要么自托管带轴的字族,要么把这档改 400。

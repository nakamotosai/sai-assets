关掉 JS 会怎样?
整层是渐进增强:html 上没有 js-motion / motion-ready,所有动效规则都不命中,页面就是静态排版;折叠退回原生 details/summary。
会不会影响首屏?
一条 script defer 即可;场只有一块 2D canvas,粒子数按面积夹在 26–88,离开视口与切后台都停帧。
怎么接自己的主题切换?
把「应用主题」的函数挂到 window.motionKit.applyTheme,切换按钮点一下就会走圆形揭示的 View Transition。

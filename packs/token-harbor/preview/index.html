为什么只有一个强调色

色相一旦承担信息,就得成体系;这套语言把信息交给字号、留白与墨纸互换,强调色只留墨本身。

为什么细线不统一成一个值

卡片描边、控件描边、交互描边要三种存在感,所以留四级:line / hairline / field / control。

FAQ

常见问题

原生 details:展开状态不用 JavaScript。

深浅两模要引几份 CSS?
单主题(近黑)只引 default.css;要在同页切换模式,再加一份 themes.css 并在 html 上写 data-theme。
强调色能不能换成别的颜色?
可以,但要改 tokens/semantic 的两个文件并重跑断言:对比度是按语义键实测的,换了色就必须重新验一遍。
表单报错为什么不是红色?
这套语言里没有色相,报错靠加粗描边、圆形叹号和文案三件事,圆点与文案都沿用墨色。

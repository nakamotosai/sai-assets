# cjk-thin-type-system · 中文细体排版语言

给中文站点装一套**极细排版**:字号 4 档、字重 2 档、字距 3 档、行高 3 档、文字影 2 档。组件只继承,不再各写一套 —— 这是把「21 种样式组合」收敛成一套语言的做法。

## 何时用细体(判据)

- **只有暗底 + 大字号**才成立:细体靠「白字在暗底上发光」显出笔画,17px 以下或亮底上就变灰、变糊。
- 一页最多两档细体字号(标语 + 正文);第三档开始,观感从「高级」滑向「没力气」。
- 需要力量感 / 数据密度 / 亮底长文时**不要用**(分别走粗体营销页、系统栈工具台、纸媒正文档)。

## 地板与阶梯(硬约束)

| 约束 | 值 | 为什么 |
|---|---|---|
| 中文最小字号 | **12px** | 再小中文的横画会并成一条灰线;12px 起必须配 400 字重,不许用细体 |
| 细体(200)最小字号 | **17px** | 越大越细:200 只准 ≥17px;300 只准 ≥14px;400 只准 ≤12px |
| 最小行高 | **1.35** | 标题档;正文 1.6,标语 1.4 |
| 第二层扩散影 | ≥28px 才准 | 发丝笔画 + 双层影 = 糊成一团,肉眼看成「字体变粗了」 |
| `vw` | 只准在 `clamp()` 中段 | 上限一律绝对单位,禁 `vw` 外推上限 |

## 何时不用这套

- 亮底纸媒长文 → `cjk-typography` 的 `article` 衬线栈 + 16–17px 正文
- 控制台 / 地图 HUD / 内网工具 → 系统栈(同上包 `sys-console` 档)
- 需要 700 字重打力量 → 本包只有 200 / 600,重档留给主题包

## 档位表

| 轴 | 档 | 值 |
|---|---|---|
| 字号 | giant | `clamp(44px, 8.2vw, 122px)` |
| | display | `clamp(28px, 3.2vw, 44px)` |
| | title | `clamp(20px, 2vw, 22px)` |
| | body | `17px`(细体地板) |
| 字重 | text 200 / mark 600 | 越大越细,详见上表 |
| 字距 | `0` / `.02em` / `.12em` | 正文 0;标题 .02em;微标签 .12em |
| 行高 | 1.4 / 1.35 / 1.6 | 大字 / 标题 / 正文 |
| 文字影 | 单层 / 双层扩散 | 第二层只给 ≥28px |

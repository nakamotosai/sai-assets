# SCOPE · 收什么、不收什么

> 公开仓的收录判据。判据是**原则**,不是名单;名单属私有工作记录,不进本仓。

## 收

| 类目 | 收什么 | 判据 |
|---|---|---|
| `themes` | 配色 + 字体 + 配对规则 + 变体 | 自产或宽松许可;能在真实站点上跑过;有断言 |
| `fonts` | 中文排版配方(字号档、字距行高、免费字体清单) | 配方可照抄;清单只列许可明确的字体 |
| `web-fx` | 网页动效(背景/过场/粒子/三维) | 有实现产物 + apply 片段 + 性能口径 |
| `web-ui` | 组件与底座 | 被真实项目用过;有活预览 |
| `references` | 外部站点的观测结论(结构/配色/版式) | 只写观测与结论,**不带原图原码** |
| `video-motion` | 视频动效,仅索引 | 运行模型不同,只登记本家地址 |

## 不收

1. **第三方品牌内容**:他人品牌标识、宣传语、人名与联系方式。
2. **客户 / 业务交付物**:客户名、业务线域名、内部数据量级、保密标记。
3. **真实媒体内容**:报道标题正文、原站配图、媒体 logo 清单。
4. **第三方镜像件**:整站镜像、自带"禁止再分发"声明的资源。
5. **许可不清或受限的素材**:来源不明、许可缺失(MISSING)、商业字体文件。
6. **空壳卡片**:只有索引条目、没有实现产物的动效卡——宁可标为"待补",不灌空壳。

## 边界

- 收录 = 公开;判据不过的一律留本地私有,不进本仓、不进 catalog。
- 收录进来的资产若长出独立受众(被外部需要、或运行模型不同),**移出成独立仓**,本仓只留 catalog 索引项,不复制内容。
- 一个包放进本仓后,原素材处的副本同轮改为索引指针,不留第二份。
